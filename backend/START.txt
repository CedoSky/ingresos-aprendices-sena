========================================
BACKEND API - SENA - START GUIDE
========================================

ARCHIVOS EN ESTA CARPETA:
- app.py              → Aplicación Flask principal
- routes.py           → Endpoints de la API
- models.py           → Modelos de base de datos
- config.py           → Configuración
- cloud_storage.py    → Integración AWS S3
- requirements.txt    → Dependencias Python
- docker-compose.yml  → Orquestación Docker
- Dockerfile          → Imagen Docker
- wsgi.py             → Entry point para producción
- .env               → Variables de entorno (copiar de .env.example)
- .env.example       → Template de variables


OPCIÓN 1: DESARROLLO LOCAL SIN DOCKER
========================================

1. Instalar PostgreSQL (https://www.postgresql.org/download/)

2. Crear base de datos:
   psql -U postgres
   CREATE DATABASE sena_aprendices_dev;
   \q

3. Instalar dependencias:
   pip install -r requirements.txt

4. Ejecutar API:
   python app.py

5. La API estará en: http://localhost:5000

6. Probar: http://localhost:5000/health


OPCIÓN 2: CON DOCKER (Recomendado)
========================================

1. Instalar Docker Desktop

2. Ejecutar:
   docker-compose up -d

3. Esperar 10 segundos

4. La API estará en: http://localhost:5000

5. Para detener:
   docker-compose down


VERIFICAR QUE FUNCIONA
========================================

1. Abrir en navegador:
   http://localhost:5000/health

2. Deberías ver algo como:
   {"status": "ok", "timestamp": "...", "s3_connected": false}

ENDPOINTS PRINCIPALES
========================================

POST   /api/auth/login                      → Login
GET    /api/personas                        → Listar personas
POST   /api/personas                        → Crear persona
PUT    /api/personas/{id}                   → Actualizar
DELETE /api/personas/{id}                   → Eliminar
POST   /api/registros-acceso                → Registrar entrada/salida
GET    /api/registros-acceso                → Ver accesos
POST   /api/respaldos/crear                 → Crear respaldo
GET    /api/respaldos                       → Ver respaldos
GET    /api/estadisticas                    → Ver estadísticas


CONFIGURACIÓN AWS S3 (Opcional)
========================================

1. Crear cuenta AWS: https://aws.amazon.com
2. Crear bucket S3
3. Crear usuario IAM con permisos S3
4. Copiar credenciales a .env:
   AWS_ACCESS_KEY_ID=...
   AWS_SECRET_ACCESS_KEY=...
   AWS_S3_BUCKET=...


ARCHIVOS MÁS IMPORTANTE POR ORDEN:
========================================

1. .env                  → Configuración (DATABASE, AWS, SECRET)
2. models.py             → Estructura de datos (Personas, Accesos, etc)
3. routes.py             → Lo que hace la API 
4. app.py                → Cómo inicia todo
5. docker-compose.yml    → Para producción


PROBLEMA COMÚN: "Database connection error"
========================================

✓ Verificar que PostgreSQL está corriendo
✓ Revisar DATABASE_URL en .env
✓ Asegurar que la base de datos existe

Si usas Docker:
✓ Esperar a que PostgreSQL esté listo (30 segundos)
✓ Ver logs: docker-compose logs postgres

ESTRUCTURA DE LA BASE DE DATOS
========================================

usuarios
├── id (UUID)
├── email
├── password_hash
└── rol (admin, supervisor, operator)

personas
├── id (UUID)
├── nombre
├── numero_doc
├── perfil (APRENDIZ, INSTRUCTOR, VISITANTE)
├── programa

└── datos_adicionales (JSON flexible)

registros_acceso
├── id (UUID)
├── persona_id
├── tipo (ENTRADA, SALIDA)
├── timestamp
└── ambiente

cambios_historial
├── id (UUID)
├── persona_id
├── campo
├── valor_anterior
└── valor_nuevo

respaldos
├── id (UUID)
├── nombre_archivo
├── s3_key
└── restaurado_en


JWT AUTHENTICATION
========================================

1. Obtener token:
   POST /api/auth/login
   → te devuelve un token

2. Usar token en peticiones:
   Header: Authorization: Bearer {token}


CÓDIGOS DE RESPUESTA HTTP
========================================

200 OK              → Operación exitosa
201 Created         → Creado exitosamente
400 Bad Request     → Datos inválidos
401 Unauthorized    → Falta token o no válido
404 Not Found       → Recurso no encontrado
500 Server Error    → Error interno

NEED HELP?
========================================

Ver logs de la API:
  docker-compose logs api

Ver logs de PostgreSQL:
  docker-compose logs postgres

Verificar que puertos estén libres:
  Windows:  netstat -ano | findstr :5000
  Linux:    lsof -i :5000

Para reiniciar todo:
  docker-compose down -v
  docker-compose up -d
