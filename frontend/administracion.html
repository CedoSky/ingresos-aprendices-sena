    Zona de Mantenimiento — Depuración

    Usa estas opciones para limpiar los datos antes de poner el sistema en producción o cuando necesites dejarlo en un estado inicial. Las acciones aquí no se pueden deshacer.

    Limpiar equipos registrados
    Elimina todos los equipos (laptops, computadores) y sus registros de movimiento. Útil para empezar desde cero antes de poner el sistema en producción.
    Eliminar equipo individual
    Ingresa el código de barras del equipo que deseas eliminar.
    Limpiar registros de acceso
    Elimina el historial de entradas y salidas y las ocupaciones de ambientes activas. Las personas registradas en el sistema permanecen intactas.
    Dejar base de datos virgen
    Elimina todo: personas, registros de acceso y ocupaciones de ambientes. El sistema quedará exactamente como recién instalado.
