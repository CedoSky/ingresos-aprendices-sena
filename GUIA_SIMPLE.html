🔧 Backend - Cómo Funciona (Servidor)

El Backend es como un "RECEPCIONISTA" del sistema: 1️⃣ RECIBE petición del Frontend ↓ 2️⃣ PREGUNTA: ¿Eres realmente quien dices ser? (Verifica JWT Token) ↓ 3️⃣ VERIFICA que los datos sean válidos (¿El formato es correcto? ¿No hay virus?) ↓ 4️⃣ PROCESA: Ejecuta la acción (guardar, actualizar, etc.) ↓ 5️⃣ CONSULTA/MODIFICA la Base de Datos ↓ 6️⃣ RESPONDE al Frontend: ✅ OK o ❌ Error

📂 Archivos Backend Importantes

Archivo ¿Qué hace?
app.py Inicia el servidor Flask
routes.py Define todas las URLs y qué hacen (/api/personas, /api/login, etc.)
models.py Define estructura de Base de Datos (Usuarios, Personas, Registros)
security_shield.py Verifica tokens, valida datos, previene ataques
mqtt_handler.py Comunica con ESP32 para abrir la cerradura
websocket_handler.py Actualiza pantalla en TIEMPO REAL sin recargar
pagos.py Procesa pagos y transacciones
export_excel.py Genera reportes en formato Excel

🔄 Flujo Completo - Ejemplo Práctico

Escenario: Usuario abre la puerta

1️⃣ Usuario selecciona "Pedro García" y presiona ABRIR
2️⃣ FRONTEND (Navegador)
- Verifica que persona esté seleccionada
- Envía petición al Backend
3️⃣ BACKEND (Servidor Flask)
- Recibe la petición
- Verifica JWT (¿es usuario válido?)
- Consulta BD: ¿existe Pedro García?
- Crea registro de acceso
4️⃣ MQTT HANDLER
- Publica mensaje en Mosquitto
- Topic: "control/acceso"
- Datos: ID persona, tipo entrada/salida
⬇️ ⬇️ ⬇️
5️⃣ ESP32 ARDUINO
- Recibe el mensaje MQTT
- Activa el GPIO 26 (Pin TRIAC)
⬇️ ⚡ ⬇️
6️⃣ TRIAC CONTROL
- Activa circuito de 110V/220V
- ⚡ SOLENOIDE se energiza
- 🔓 CERRADURA ABRE (3-5 segundos)
- Después cierra automáticamente
⬇️ ✅ ⬇️
7️⃣ RESPUESTA
- Backend responde al Frontend: ✅ Acceso registrado
- Frontend muestra: "Puerta abierta"
- Pantalla se actualiza automáticamente (WebSocket)

🔀 Frontend vs Backend - Diferencias

Frontend 🖥️ (Lo que ves)

  • ✅ Botones, formularios
  • ✅ Colores, diseño
  • ✅ Validaciones simples
  • ✅ Mensajes amigables
  • ✅ Corre en tu navegador
  • ✅ HTML, CSS, JavaScript

Backend 🌐 (Lo que no ves)

  • 🔐 Seguridad avanzada
  • 🔐 Encriptación de datos
  • 🔐 Validaciones de seguridad
  • 💾 Guarda en Base de Datos
  • 📡 Comunica con ESP32
  • 🐍 Python (Flask)

📞 Comunicación Frontend ↔ Backend

FRONTEND BACKEND (Navegador) (Servidor Puerto 8000) │ │ │──── POST /api/login ───────────► │ │ (Email + Password) │ Valida credenciales │ │ │◄─────── JWT Token ───────────────│ │ (Autorización) │ │ │ │──── GET /api/personas ──────────►│ │ (Con JWT incluido) │ Consulta BD │ │ │◄─────── JSON Array ───────────────│ │ (Lista de personas) │ │ │ │──── POST /api/registros ────────►│ │ (Abre puerta) │ Publica MQTT │ │ Guarda en BD │◄─── Confirmación ✅ OK ──────────│ │ │ Tabla se actualiza Cerradura abre (en tiempo real) 🔓

🔐 ¿Cómo se protegen los datos?

⚠️ Datos Sensibles (Protegidos)

  • 📧 Emails
  • 🔐 Contraseñas
  • 📱 Teléfonos
  • 🆔 Documentos de identidad
  • 💳 Datos de pago

✅ Protección Implementada

JWT Token Autorización + sesión segura
Encriptación Fernet Datos guardados encriptados en BD
Hash bcrypt Contraseñas con hash irreversible
HTTPS (en producción) Los datos viajan encriptados
Validación de entrada Se rechaza datos malformados
Rate Limiting Se bloquea después de 5 intentos fallidos
